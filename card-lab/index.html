Card Lab · 2 张源卡 × 5 个方向

数据卡面实验室FROM INK SILHOUETTE TO RUNTIME DATA

两张剪影卡面被当作像素数据直接读入，每个方向都在浏览器里逐像素实时重算，没有额外绘制素材。把指针移到卡上看交互，点击卡面重播入场动画。卡名、数值和技能文字是占位示例。

AGLYPH

字码

ASCII Terminal

每 9×12 的格子按明暗挑一个等宽字符，红色刀光改写成 / \ < > 0 1。入场像终端逐行解码，平时有几条红色数据流沿列下落。

交互
指针周围的字符翻成十六进制乱码
适合
黑客、终端、档案题材；读起来最“代码”的一种
BHUD

战术扫描

Tactical Scan

先做 Sobel 边缘检测，只留下轮廓线和斜线排线。扫描线自上而下把角色“扫”出来，关键部位挂着坐标标签，原画里的圆环变成雷达。

交互
十字准星跟随指针并读出坐标
适合
机甲、军事、科幻；战斗中的锁定和情报界面
CDITHER

点阵档案

1-bit Print

4×4 Bayer 有序抖动，只用纸、墨、朱三色。入场从 15×20 的粗像素逐级加载到 150×200，配条形码、编号和朱红认证章，像一张打印出来的身份卡。

交互
“解密透镜”：指针处显示原图
适合
像素风、复古掌机；最容易统一整套牌的批量产出
DGLITCH

数据损坏

Corrupted Sector

保留原画，再在上面做破坏：横向切片错位、朱红通道偏移、局部马赛克。每隔两三秒一次“崩溃”，弹出内存窗口，显示的是这一行真实的像素字节。

交互
指针停留时持续故障
适合
稀有卡、被污染或觉醒的变体；与原画风格最接近
EPOINT CLOUD

粒子点云

Point Cloud

从墨色、灰色和朱红像素采样约五千个点，各自弹回原位。刀光粒子轻微游动，圆环与十字保留为细线，费用改用原画里的四角星。

交互
指针推开粒子；点击炸散后重新聚合
适合
抽卡展示、卡牌详情、传说级卡；动效最强

C 点阵做手牌里的常态卡面，悬停或打出时切到 B 扫描，稀有卡叠 D 故障层，抽到传说卡时播 E 的聚合动画。

原画怎么配合

原画的平涂剪影和少量朱红很适合做数据化：三种颜色分得干净，取样不会糊。后续新卡保持“纸、墨、灰、朱”四档就能直接套用。

全息倾斜

右上角的开关给所有方向加了收藏卡式的倾斜和镭射反光，是独立的 CSS 层，可以和任何方向组合。
