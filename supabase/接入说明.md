# 留言与点赞接入

当前没有配置真实服务，页面明确显示「暂未开放」，不会显示假留言或虚构公共计数。游戏主体无后端依赖。

1. 在免费 Supabase 项目中打开 Authentication → Providers → Anonymous Sign-Ins。开启匿名登录，无需访客注册。不要升级付费。
2. 在 SQL Editor 执行本目录的 `schema.sql`。该文件可重复运行。访问限制保留：只能新增自己的留言、读公开留言，不能编辑/删除他人留言；只能操作自己的点赞。计数是只读函数，不接受客户端覆盖。
3. 在 Project Settings → API 找到 Project URL 与 publishable key（或旧 anon key），填入根目录 `community-config.js`。两项为公开配置；**不要使用 secret key、service_role 或管理员密钥**。
4. 提交 Git，等待 GitHub Pages 发布。匿名身份保存在此浏览器的本地存储，清理存储/更换浏览器可能创建新身份，点赞数不代表唯一真人。
5. 在两个独立浏览器会话中验证：互相读取留言、分页、点赞增加、取消点赞减少；断网提交保留内容；`<img src=x onerror=alert(1)>` 按纯文字显示。验证未登录/伪造 user_id 无法写入，不能更新别人的留言或删除别人的点赞。
6. 管理删除在 Supabase Table Editor 完成，不把管理权限送入网页。删除后另一会话重新打开留言面板应不再看到该条。

按本版需求，提交后直接公开，不增加验证码、预审或额外防刷。因此公开入口有滥用风险；Supabase 自带服务限额仍然生效，请关注免费额度。网络/认证/服务失败只影响社区，不阻断游戏。
