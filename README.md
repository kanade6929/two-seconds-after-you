# 辰星夜 · 大阿卡那

循着八张牌的微光，与两秒前的自己，走过这一夜。

原生 JavaScript / Canvas 2D 的八关短篇解谜游戏。支持 PC 与手机，无需账号；游戏可离线。原名《两秒之后的你》，保留已有目录和网址。

网站：https://kanade6929.github.io/two-seconds-after-you/

本地双击 `index.html`，或运行 `node server.cjs` 后打开 http://127.0.0.1:4173 。游戏无需 npm 依赖。

## 这一版怎么玩

- **实时回声**：暖金影子准确重播两秒前的实际位置与按下状态。停留会被重播，不会永久接手；安排停留与离开的时机，让两束光合作。
- **PC**：菜单使用系统鼠标；关内用青色光点，点击按其实际位置判定，不会等待光点赶到后补触发。速度上限 420 单位/秒，加速度 1600，保留缓动防抖。
- **手机**：底部一个光域，滑动移动、轻点确认；也可轻触场景选目的地。拖动抬手不误点，无谜题需要长按。PC 与手机规则相同。
- **容错**：魔术师可撤回转印，任何时候可重建回声；暂停中可以重置谜题。错误不罚时间。25 秒无进展可按「启示」看两级提示。
- **暂停**：失焦、切后台、旋转屏幕或窗口调整暂停。继续一次即可接回原处，暂停时间不计入回放。Tab / Enter / Esc 保留。
- 解题的最后一步就是结束，不再单独冲向通用大门。允许确认时显示呼吸框；月亮所有候选反馈一致，不提前泄露正误。

## 源码、视觉与存档

`rules.js` 保存八关数据与判定；`core.js` 负责 120 Hz 时钟、限速、回放、撤回与回声重建；`render.js` 只绘图；`symbols.js` 保存直线图腾；`app.js` 管理 UI、触控、音效、暂停和存档。

夜色、青白与暖金光效，纯直线塔罗符号。青色拖尾 1.15 秒、暖金 0.6 秒，两束光都保留短曲线拖尾。局部颜色场与完整路径遮罩保留交叉抗闪动；机关渐亮/熄灭、粒子、呼吸和全屏过关光波保留。

手机缓存夜空、光晕及局部轨迹缓冲；几何曲线 30 Hz 取样，逻辑 120 Hz。关内目标 60 FPS，菜单背景 30 FPS；持续帧压力时 Canvas DPR 从最高 2 分档下降至 1.25，HTML 字体和光点保持设备清晰度。这是性能策略，不代表已在安卓真机达到 60 FPS。

全局字体为用户提供并授权网页/Git 发布的方正清刻本悦宋简体，见 `assets/字体说明.md`。

存档键为 `two-seconds-after-you.arcana.v4`。继承 v3/v2 解锁与声音、动态设置，旧存档不删除；不迁入静态玩法检查点。保存折印方向与世界接边，刷新后重新建立真实回放，不恢复半段轨迹、临时供能或水位。存储不可用仍可游玩，但刷新会丢失本次进度。

## 验证与发布

基础测试：`node --test tests/*.test.cjs`。设置 `ECHO_CANVAS_MODULE` 为已安装的 `@napi-rs/canvas` 可启用五项像素回归。浏览器测试需要 Playwright；可通过 `ECHO_PLAYWRIGHT_MODULE` 指定其路径。

```text
node tests/browser-check.cjs chrome msedge chrome-mobile chrome-mobile-landscape
node tests/browser-regression.cjs
node tests/targeted-check.cjs
node tests/moon-check.cjs
node tests/touch-browser-check.cjs
node tests/temperance-browser.cjs
```

后三组检查使用完整求解器产生的存档，不直接设置解锁状态。输入经过真实网页鼠标/触控处理器，但运行于隔离无头浏览器及触控模拟，不能代替安卓真机、人工手感和首通时长验收。实际结果见 `验收记录.md`。

推送 main 后 CI 先测试再发布运行文件和字体。`node pages.mjs --status --jobs` 查看工作流；`node pages.mjs --verify` 比对线上源码和字体摘要。测试、文档和 SQL 不进入网站运行目录。
