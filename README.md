# 两秒之后的你

一个用鼠标和两秒前的自己合作的八关夜色解谜游戏。

## 开始

用 PC 版 Chrome 或 Edge 双击打开本目录的 `index.html`。所有素材和脚本都在本地，无需联网、账号或安装依赖。也可在本目录执行 `node server.cjs`，访问 http://127.0.0.1:4173 。

移动鼠标控制青白色光点。暖金色光点会在两秒后重复你的平滑轨迹和按下状态。停留即可触发圆形开关，出口打开后点击出口。鼠标可以在整个页面活动，包括标题栏与底栏所在区域。

影子的回放延迟固定两秒。第一关用短停留学习接手；后续需要交换身份、穿闸、点击暗号、追踪移动机关、亮度平衡和光弦瞄准。所有新规则会显示在关卡说明中，25 秒后可展开详细提示。第一关错过开门窗口进入只有“重试”的结果页；后续关卡允许继续调整，阶段进度保留到主动重试。

首页提供“开始这场合作”（已有进度时显示“从第一束光开始”）、“继续游戏”和“选择关卡”。继续游戏从最近进入的关卡重新开始；通关后会指向下一关，不保存关内鼠标轨迹。重玩第一关不会清除解锁记录。旧三关版已全部完成的存档会自动解锁第四关。

## 八个瞬间

| 章节 | 玩法 |
| --- | --- |
| 01 留一下 | 让影子接手开关，当前光点前往出口。 |
| 02 交换位置 | 完成昔左现右，再交换为昔右现左；各共鸣 0.3 秒。 |
| 03 借光穿行 | 影子开闸，当前光点必须从中央光隙穿越，不能绕过屏障。 |
| 04 迟来的暗号 | 点击乙→甲→乙→丙；只接受两秒后重播的点击，错误清空输入。 |
| 05 追光与对拍 | 暖金守位，青白追踪公转机关 0.55 秒；共鸣后按门环亮拍点击。 |
| 06 恰好的余温 | 三盏灯同时保持 35%—85% 亮度 0.4 秒；影子同样会充能。 |
| 07 拨动光弦 | 影子守锚点，两束光之间的直线按序扫过三枚棱晶。 |
| 08 夜的合奏 | 先输入暗号，再光弦扫双晶，最后对拍叩门。 |

离开浏览器页面、切换窗口或调整窗口大小会暂停。点击“继续”后，再点击标出的原光点位置续接。Esc 也能暂停。章节菜单可重玩已解锁关卡。“重新来过”只清空当前关卡。

声音、动态设置和解锁进度保存在当前浏览器本地；不同浏览器或本地文件与 HTTP 预览之间的存档不共享。浏览器禁用存储时仍可正常玩，但刷新会丢失进度。

## 源码

- `core.js`：临界阻尼跟随、时间轨迹、插值回放、八个关卡、存档迁移与机关判定；120 Hz 固定步长。机关判定与回放使用同一个平滑位置。
- `render.js`：Canvas 2D 绘制和逻辑坐标转换。
- `app.js`：页面状态、输入、暂停续接、音效和存档。
- `style.css` / `index.html`：中文界面与布局。

测试：`node --test tests/*.test.cjs`。不需要 npm 依赖。轨迹每帧以完整贝塞尔路径绘制线芯与柔光，不再逐段叠加圆头。背景有缓慢漂移的微粒；点亮的机关周围有持续环绕光屑，亮度随机关一起渐熄，鼠标轨迹不撒点。临时粒子池上限 240；环绕粒子和通关光屑由固定数量的解析式绘制，不无限分配。成功开门有收拢光环、中心绽放、三层光波、100 道放射光屑与横向光芒，约 2.6 秒后显示结果。

减少动态模式缩短拖尾、关闭呼吸和粒子，通关改为 0.45 秒局部柔光。按钮支持悬停与按下反馈，界面进场约 420 毫秒、退场约 170 毫秒；快速切换会取消旧动画，隐藏层不再接收输入。音效由 Web Audio 合成，未调用图像 API。

当前共 34 项自动化测试，包含八关解法、错误站位、闸门防跳过、延迟点击、错拍拒绝、光弦顺序、存档迁移、隔离 DOM 中的真实页面控制器，以及绘图调用层检查。尚未完成实际浏览器截图、真实鼠标手感或设备帧率验收。

切到后台会停止游戏更新和渲染，暂停/菜单会冻结场景特效时间。存档仅在浏览器本地保存，无账号、联网素材、追踪分析或 API Key。网站与本地预览因来源不同而分别保存进度。

## 发布

`deploy.mjs` 从环境变量读取 Netlify 授权，通过系统 Git 凭据管理器读取 GitHub 授权；不在源码中保存密钥。`--check` 检查授权，`--create` 创建独立仓库/站点，`--publish` 将五个游戏运行文件上传到草稿部署、发布并校验线上哈希。部署记录 `.deployment.local.json` 已在 Git 中忽略。线上只发布入口、样式和三个 JS 文件。

本作以 PC 鼠标为目标设备；窄屏可显示，但不承诺手机触屏玩法。建议使用至少 960 × 640 的浏览器窗口。
