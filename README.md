# 辰星夜 · 大阿卡那

循着八张牌的微光，与两秒前的自己，走过这一夜。

原生 JavaScript / Canvas 2D 解谜游戏，八关重制，支持 PC 鼠标与手机触屏。无需账号；游戏本身可离线，留言与点赞独立接入 Supabase。

原名《两秒之后的你》。为保持已有链接和存档兼容，本地目录、Git 仓库地址及存档键不改名。

## 游玩

网站：https://kanade6929.github.io/two-seconds-after-you/

本地双击 `index.html`，或运行 `node server.cjs` 后打开 http://127.0.0.1:4173 。无需安装 npm 依赖。

- PC：主页、选关、暂停、过关和留言菜单使用系统鼠标；进入关卡后由青色光点代替鼠标，关内按钮也按**青色点的位置**响应，不会补触发提前点击。光点上限 420 单位/秒，加速度上限 1600 单位/秒²，保留缓动防抖。Tab / Enter 可操作按钮，Esc 暂停。
- 手机：菜单直接轻触。关内在底部「光域」滑动移动，或轻触场景设置目的地；青色点仍按相同速度缓动前往。点击右侧「确认」操作折印、真纹、世界环片或出口；恋人和太阳末阵需按住确认。抬手不会让光点回弹。
- 暖金影子准确重复两秒前的位置及按下状态；停留多久，它就停留多久，不会永久接手。
- 进入机关内边框建立占位，外边框是离开边界。印内微移不再掉电；离开外框立即失效，余光不算供能。
- 结尾就是本关谜题的最后一步，不再追加通用门印。可点击终点会呼吸闪光，并显示「点击完成」；减少动态时保留常亮边框与文字。
- 换阵时旧机关渐隐、新机关渐亮，约 0.44 秒；期间冻结游戏时钟和点击，不占用合作窗口。
- 失误只重试本阵，已完成阶段保留。25 秒没有阶段进展时可按「启示」。没有死亡次数或总倒计时。
- 离开页面、失焦、窗口调整/横竖屏切换会暂停；点击继续一次即可接回原光点。手机抬手不会暂停。

## 源码与美术

`rules.js` 为八个独立规则处理器、完成条件及数据；`core.js` 为限速跟随、120 Hz 时钟、轨迹回放、碰撞和换阵冻结；`render.js` 只绘图；`symbols.js` 为纯直线图腾；`app.js` 管理交互、触屏、音效、状态和存档。

青色拖尾 1.15 秒、暖金 0.6 秒，使用局部颜色场 + 完整路径遮罩避免交叉闪动与接缝亮珠。机关渐亮/熄灭、呼吸、粒子与全屏光波保留；减少动态不改变规则。手机重排信息与控制区，按关卡取景，Canvas 像素密度上限 2，粒子池有界，不降低两秒回放精度。

手机性能：状态变化才写入界面；缓存夜空/光晕，轨迹只分配局部缓冲；图腾合并描边。手机曲线每秒取 30 个几何节点并持续平滑绘制，物理与回放仍为 120 Hz。关内画面目标 60 FPS，静态菜单背景 30 FPS；持续帧压力时将 Canvas 密度从 2 分档降至最低 1.25，HTML 字体、按钮和顶层光点仍保持设备原生清晰度。不以关闭粒子或改变规则换取速度。

全局使用用户提供且确认可网页/Git 发布的方正清刻本悦宋简体，包含 Canvas 文本；原字体及许可来源说明见 `assets/字体说明.md`。版权仍属于原权利人。

## 社区接入

当前**没有配置真实 Supabase**，留言/点赞显示「暂未开放」，不显示假公共数据，也不影响游戏。

配置 `community-config.js`，执行 `supabase/schema.sql`，按 `supabase/接入说明.md` 完成匿名认证、RLS 和双会话验证。只填公开 Project URL / publishable key；不要将 service_role 或管理员密钥放进网页或 Git。

## 验证与发布

基础测试：`node --test tests/*.test.cjs`。可选 `ECHO_CANVAS_MODULE` 指向已安装的 `@napi-rs/canvas`，启用 5 项像素回归。浏览器测试设置 `ECHO_PLAYWRIGHT_MODULE` 指向 Playwright 后运行：

```text
node tests/browser-check.cjs chrome msedge chrome-mobile chrome-mobile-landscape
node tests/browser-regression.cjs
```

浏览器脚本通过真实页面鼠标/触控输入求解，不直接改通关变量，但属于隔离无头浏览器及设备模拟，不是实体手机、人类手感或实际 GPU 帧率验收。详见 `验收记录.md`。

推送 main 后 GitHub Actions 先测试再发布运行文件与字体。`node pages.mjs --status --jobs` 检查工作流，`node pages.mjs --verify` 比对线上文本和字体二进制摘要。源码、SQL、测试不进入网站发布目录。
