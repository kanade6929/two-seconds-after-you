# 星潮之间 / Between Star Tides

为《辰星夜》新写的程序合成纯音乐，不含采样、人声、第三方乐曲录音或参考曲旋律转录。

- 80 BPM，4/4，32 小节，96 秒循环。
- B 小调与 D 大调相邻色彩；延伸和弦、失谐柔垫、FM 电钢/钟音、立体声琶音、低音与稀疏轻节拍。
- 四段配器由疏到密再回落。延迟尾音循环折回，避免末尾硬切。
- 用户提供《Galax Gate》作为方向参考；本版未取得或分析该录音，不宣称与其音色、旋律、结构或听感精准一致。
- 可编辑谱面和渲染器：`scripts/render-music.cjs`；运行 `node scripts/render-music.cjs <ffmpeg可执行文件>` 可重建 WAV 与发布 MP3。WAV 保存在忽略的 `artifacts/music`，MP3 随网站发布。
- 112 kbps / 32 kHz / 立体声 MP3，约 1.35 MB。浏览器解码后单源精确循环，不在绘制循环中合成或排音符。
- 第一次用户手势后开始淡入，与现有“声音”按钮共同控制；暂停界面减弱，切后台停止并记住进度，通关降至更低音量后恢复。不因换关重新从头播放。
- 音频加载失败不影响玩法，无额外账号、API 或付费服务。file:// 下浏览器可能禁止加载音频，使用附带本地服务器或线上站点可正常加载。

播放器：`music.js`。总静音沿用现有存档设置，不新增视觉控件。
